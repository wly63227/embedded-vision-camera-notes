# 嵌入式开发完整学习路线

一套面向零基础到独立完成项目的中文嵌入式开发课程。主线以 **C 语言 + STM32** 为例，保留 **ESP32 / FreeRTOS** 分支；重点不是背 API，而是建立“读手册—写驱动—测波形—定位故障”的工程能力。

## 学完能做什么

- 看懂原理图、数据手册和参考手册，完成 GPIO、定时器、UART、ADC、I²C、SPI 等外设开发。
- 用中断、DMA、状态机、环形缓冲区组织可靠的裸机程序。
- 使用 FreeRTOS 设计任务、队列、互斥量和软件定时器，并识别常见并发问题。
- 完成一个可演示、可测试、可复现的综合项目，并将其整理成作品集。
- 具备继续学习嵌入式 Linux、驱动、低功耗、控制算法或物联网的基础。

## 推荐硬件

两条路线任选其一，不需要同时购买：

| 路线 | 推荐开发板 | 适合目标 | 额外器件 |
|---|---|---|---|
| STM32 主线 | NUCLEO-G071RB、NUCLEO-F401RE，或常见 STM32F103C8T6 板 | MCU 基础、工业控制、求职 | 面包板、LED、按键、0.96 寸 I²C OLED、BME280/AHT20、逻辑分析仪（可选） |
| ESP32 分支 | ESP32-DevKitC / ESP32-S3 DevKit | Wi-Fi、蓝牙、物联网 | 同上，注意使用 3.3 V 器件 |

> 不要在没有确认电平和供电要求时直接连接模块。GPIO 通常不能承受 5 V；电机、继电器等负载也不能由 GPIO 直接驱动。

## 如何使用这套资料

1. 阅读 [学习计划](docs/00-roadmap.md)，确定每周节奏。
2. 按章节顺序学习，每章都完成“最小实验”和“验收标准”。
3. 在 [学习记录模板](docs/learning-log.md) 中记录现象、证据和问题。
4. 先自己排查，再看 [调试手册](docs/09-debugging.md)。
5. 第 12 周完成 [环境监测终端](projects/environment-monitor.md)，形成作品集。
6. 每完成一个阶段，用 [阶段自测题](docs/self-assessment.md) 检查是否真正掌握。

建议每周投入 6～10 小时：理论 30%，动手 60%，复盘 10%。如果没有开发板，可先完成 C 语言、状态机、环形缓冲区和主机端测试。

## 学习原则

- **先测量，再猜测**：串口日志、断点、寄存器、万用表和逻辑分析仪都是证据。
- **先最小闭环，再堆功能**：先让一个 LED 可控，再加按键；先读出传感器 ID，再解析数据。
- **中断只做必要工作**：记录事件或搬运数据，复杂逻辑放到主循环或任务中。
- **避免阻塞式延时**：除最初的点灯实验外，优先使用时间戳、状态机或 RTOS 延时。
- **每次提交只解决一个问题**：保持可回退、可比较、可复现。
