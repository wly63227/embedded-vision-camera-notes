# 阶段自测题

先口头回答，再用实验验证。答案不在本页集中给出，因为能通过手册、代码和测量证明，才算真正掌握。

## C 与内存

1. 为什么 `uint8_t buffer[8]` 传入函数后无法用 `sizeof` 得到 8？
2. `const volatile uint32_t *status` 中两个限定符各约束什么？
3. 如何证明一个整数运算会不会溢出？
4. 头文件中定义全局变量为何可能造成重复定义？正确做法是什么？

## MCU 与中断

1. 复位后，`.data` 和 `.bss` 如何得到初始值？
2. ISR 与主循环共享标志时，为什么仅加 `volatile` 不一定安全？
3. 中断优先级数值越小是否一定越低？如何确认？
4. 在断点处暂停 CPU 时，外设为何可能继续运行？

## 外设

1. 开漏输出为何需要上拉？
2. 改变系统时钟后，UART 波特率和 PWM 会怎样变化？
3. I²C 设备地址 `0x76` 与某些 API 要求的 `0xEC` 有什么关系？
4. SPI 模式不匹配时，逻辑分析仪上可能看到什么？
5. ADC 分辨率高是否意味着测量一定准确？

## 架构与 RTOS

1. 什么时候协作式状态机比 RTOS 更合适？
2. 队列满时系统应该怎么办？为什么没有统一答案？
3. 二值信号量和互斥量在所有权与优先级继承方面有何区别？
4. 如何设计喂狗逻辑才能发现“某个任务卡死但其他任务仍运行”？

## 调试挑战

任选三个故障，在 30 分钟内给出证据链：

- LED 不亮；UART 乱码；I²C 无 ACK；PWM 频率减半；随机 HardFault；FreeRTOS 高优先级任务饿死低优先级任务。

合格报告必须包括最小复现、至少两个假设、区分实验、根因、修复和回归测试。
