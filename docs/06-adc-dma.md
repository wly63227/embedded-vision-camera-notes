# 06｜ADC、DMA、滤波与标定

## ADC 基础

N 位 ADC 的理想码值范围为 `0` 到 `2^N - 1`。以参考电压 `Vref` 为基准：

```text
Vin ≈ code × Vref / (2^N - 1)
```

实际系统还受参考电压误差、输入阻抗、采样时间、噪声、偏移和非线性影响。高阻信号源需要更长采样时间或缓冲运放。

## DMA 的价值

DMA 在外设与内存之间搬运数据，减少 CPU 逐样本介入。常用组合是“定时器触发 ADC + DMA 循环缓冲区 + 半满/全满事件”。处理速度必须跟得上采样速度，否则会覆盖尚未处理的数据。

## 简单滤波

移动平均适合降低随机噪声，但会增加延迟：

```c
sum += new_sample;
sum -= oldest_sample;
average = sum / window_size;
```

一阶 IIR 可用定点形式：

```text
y += alpha × (x - y)
```

先明确带宽、延迟和内存要求，再选择滤波器；不要为了“曲线好看”掩盖真实瞬态。

## 标定

用两个或多个已知输入点记录 ADC 码值，拟合增益和偏移。保存标定参数时应包含版本、范围和校验；Flash 擦写次数有限，不能在高频循环中反复保存。

## 实验：稳定采样器

1. 定时器以 1 kHz 触发 ADC。
2. DMA 每 100 个样本产生处理事件。
3. 输出最小值、最大值、均值和峰峰值。
4. 对比原始数据、8 点移动平均和一阶 IIR。
5. 改变采样时间，观察高阻输入的变化。

## 验收标准

- 采样频率由硬件定时器决定，而不是软件延时。
- 中间乘法使用足够宽的类型，避免溢出。
- 能区分精度、分辨率、重复性和采样率。
- 用万用表或已知参考值给出误差记录。
