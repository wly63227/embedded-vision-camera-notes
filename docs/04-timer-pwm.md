# 04｜时钟、定时器与 PWM

## 先算清时钟

外设频率通常来自内部/外部时钟，经 PLL、总线分频后到达定时器。不要只看 CPU 主频；应在时钟树和参考手册中确认定时器输入频率。

常见向上计数定时器近似关系：

```text
counter_frequency = timer_clock / (prescaler + 1)
update_frequency  = counter_frequency / (auto_reload + 1)
PWM_frequency     = update_frequency
duty_cycle        = compare / (auto_reload + 1)
```

具体芯片可能存在总线分频导致定时器倍频等规则，必须查参考手册。

## 定时器能做什么

- 周期中断、单次定时、输入捕获、输出比较。
- PWM、编码器接口、互补输出、死区（高级定时器）。
- 触发 ADC/DMA，建立低抖动采样链路。

## 实验 A：测量而不是相信

配置 1 kHz、25% 占空比 PWM。用逻辑分析仪或示波器测量周期和高电平时间，记录计算值与实测值。没有仪器时，可降低到 1 Hz 并用串口时间戳做初步验证，但这不能替代真正的波形测量。

## 实验 B：无阻塞呼吸灯

每 10 ms 更新一次占空比，使用查表或整数步进完成渐亮渐暗。亮度感知近似非线性，可使用 gamma 查找表改善视觉效果。

## 常见故障

- 引脚未配置为正确的复用功能。
- 定时器通道与物理引脚映射错误。
- 忘记启动通道或主输出使能。
- 计数器位宽溢出，或中间计算使用了过窄类型。
- 在 ISR 内做浮点运算或日志输出导致超时。

## 验收标准

- 能从目标频率反推 PSC 和 ARR，并说明分辨率取舍。
- PWM 实测误差在时钟源精度和仪器误差允许范围内。
- 改变主频后，能找到并修正所有受影响的时间基准。
