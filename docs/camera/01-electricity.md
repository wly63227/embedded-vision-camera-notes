# 01｜电学与接线：先理解回路

**前置：** 00。**硬件：** 暂时只需万用表、面包板、导线、LED、1 kΩ 电阻；开发板 USB 供电。**产出：** 一张实测接线图。

## 电压、电流和地

把电压想成两个点之间的“推动差”，电流是流过导线的电荷流。电压必须说明相对于哪个点。GND 是系统选定的参考点，不是一个能吞掉任意电流的黑洞。电路需要闭合的去路和回路。

电阻关系为 `U=I×R`。若 3.3 V 供电、LED 正向压降约 2.0 V，串联 1 kΩ，则电流约 `(3.3-2.0)/1000=1.3 mA`。压降会随 LED 颜色和电流变化；这个算例解释数量级，实际查器件参数。不要直接把 LED 跨接电源。

GPIO 是 MCU 的通用输入输出脚，逻辑电平用于传递信号，不能替舵机提供动力。3.3 V 是逻辑电压，不等于“整块板每个引脚都能安全接 3.3 V 大电流”。电压容限、单脚电流和总电流限制要分别查手册。

## 万用表怎么用

黑笔插 COM；红笔先放电压/电阻插孔，选择直流电压档。测电压时两表笔跨接两点；测电阻或通断前先断电。测电流要断开回路串入表，初学实验不要求做。**不能用电流档直接跨接电源两端**，那会造成近似短路。

面包板同排孔可能相连，电源轨也可能中间断开。断电时用通断档确认，不能只看颜色。模块上的红黑线只是习惯，接线前看丝印和说明书。

## 实操 L01

1. 所有外设先断开，只给开发板接 USB；黑笔接板上 GND，测 3V3。
2. 拔 USB，确认面包板孔的连通关系。
3. 按 `3V3 → 1 kΩ → LED 正极 → LED 负极 → GND` 连接，复查后上电。
4. 测电阻两端电压，用 `I=U/R` 估计电流，比较算例。
5. 在记录里画出去路与回路，并标明每个测量点。

不要把外置舵机电源的 +5 V 接到开发板 3V3；后续只把二者的 **GND 相连**建立信号参考。舵机大电流回路直接回电源端，不绕过开发板或面包板细电源轨。具体接线见 [硬件表](hardware.md)。

**通过条件：** 能测到合理的 3V3；LED 受电阻限制正常点亮；能解释为何断电接线、为何不能 GPIO 驱动电机。
