# 从零开始：会观察、会构图的云台相机

这套课以你的最终作品倒推学习顺序：**电脑看懂画面，STM32 控制两轴云台，让主体停在你指定的位置，并根据画面评估曝光与清晰度。** 第一版追踪彩色物体；第二版识别人脸或物体；第三版才迁移到独立边缘设备。

## 零基础从哪里开始

不要求会 C、Python、电子电路或高等数学。先完成 [第 00 课](00-start.md)，再照 [学习计划](syllabus.md) 前进。每课按“现象 → 概念 → 算例 → 实操 → 验收 → 练习”学习。不会的词查 [术语表](glossary.md)，遇到问题先翻 [排错手册](troubleshooting.md)。

一节课可以用三次学习完成：第一次读概念并手算；第二次接线、运行和测量；第三次改一个参数，记录失败和解释。建议每周 6～8 小时，约 20 周；验收没通过就重复该阶段，日期不作为硬性进度。

## 系统分工

```text
USB 相机 → 电脑 Python/OpenCV → 检测主体 → 选择构图点
                                      ↓
相机参数能力探测 ← 画面质量评估       位置误差与比例控制
                                      ↓ USB 虚拟串口
                           STM32：校验、限幅、超时停机
                                      ↓ PWM
                         两个位置舵机 → 改变相机朝向
```

摄像头采集的画面重新进入程序，形成闭环。舵机内部通常有自己的角度控制，但本课程没有外部角度传感器，不能把“发出的脉宽”当成“测得的真实角度”。

第一版是桌面轻载**方向云台**，不等于手持拍摄的三轴增稳云台。它不能通过转动改变物体之间的透视关系，也不能替代移动机位、变焦和审美判断。

## 三个可交付版本

| 版本 | 你真正能展示的结果 | 到达条件 |
|---|---|---|
| V0，无硬件 | 合成目标驱动模拟云台；切换居中/三分点；错误帧被拒绝 | 00～03、07～09 |
| V1，300～500 元预算 | 轻型 USB 相机追踪绿色目标，构图点可切换，断线停止输出 | 04～09、12 |
| V2，模式识别 | 人脸或物体检测、主体选择、记录误检漏检；有兼容相机时验证曝光调节 | 10～12 |
| V3，后续采购 | 树莓派独立运行、CSI 相机曝光/增益/对焦控制 | 13 |

V1 的预算是采购限额，不是实时电商报价；超限时先用笔记本摄像头练视觉，把外置摄像头延后购买。只有外置轻型摄像头才能安装到微型云台上。

## 学习时必须保留的证据

每次记录：本次问题、接线图、程序版本、只改变的一个变量、预期、实际现象、日志或波形、结论。复制 [实验记录模板](learning-log.md) 到自己的笔记里；用“看到云台动了”代替不了“方向正确、误差下降、丢失后停止”。
