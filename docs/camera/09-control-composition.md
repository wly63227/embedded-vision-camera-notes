# 09｜构图与反馈控制：让误差逐渐变小

**前置：** 05、06、08。**硬件：** 先运行模拟，后接轻载两轴云台。**产出：** 居中和三分点两种构图演示。

## 构图点不是天然答案

画面坐标归一化到 0～1。居中构图目标为 `(0.5,0.5)`，左上三分交点为 `(1/3,1/3)`。第一版只把主体中心放到目标点，不保证头顶留白、视线方向或背景整洁。以后可用人脸眼睛位置和主体朝向改进。

定义 `e_x = x_subject - x_target`、`e_y = y_subject - y_target`。例如 640 像素宽，主体 x=480，目标为 1/3 处，则 `e_x=480/640-1/3≈0.4167`。不要误把“目标在画面三分之一处”理解成误差永远等于三分之一。

## 用比例控制改变速度

本库采用“位置误差 → 脉宽变化速度”，而非把误差直接当绝对角度：

```text
误差在死区内：速度 = 0
否则：速度 = clamp(sign × Kp × e, -最大速度, +最大速度)
新脉宽 = clamp(旧脉宽 + 速度 × dt, 最小脉宽, 最大脉宽)
```

`Kp` 的单位是 μs/s 每单位归一化误差，`dt` 是秒。死区例如 0.025 表示画面宽高的 2.5%；限速用于减少突变。默认 Kp=240，速度上限 120 μs/s，真实机械仍须先减半调试。

`sign` 取 +1 或 -1，由实际安装决定。让目标在画面右边，脱载或低速只动很小一步，观察目标是否更靠近构图点。若误差扩大，立即 STOP，反转该轴 sign。两个轴分别标定，不能只凭“顺时针”猜。

## 控制频率与延迟

图像处理 15 Hz 不等于舵机输出脉冲频率；PWM 可以稳定在 50 Hz，控制目标按图像更新。积压的旧帧会造成明显延迟。当前基础程序无法取得每种 USB 相机的真实曝光时间戳，因此软件接收时间只反映应用处理时间；真实端到端延迟用拍摄时钟或闪灯实验测量。

## 实操 L09

1. 模拟中比较 Kp=120、240、480，观察误差下降速度。
2. 实物先单轴、低速、小角度，标定两个 sign。
3. 切换 `--target-x 0.333333 --target-y 0.333333`，拍对照视频。
4. 主体移出画面，检查停止；重新运行时由用户主动重新开始。

**通过条件：** 规定光照和距离下，静止目标连续 2 秒保持两轴误差绝对值均低于 0.05；记录限幅占用、目标丢失和退出状态。此为实验目标，未经实测不能声称达标。
