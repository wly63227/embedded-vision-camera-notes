# 05｜定时器、PWM 与两轴舵机

**前置：** 01、04。**硬件：** 位置舵机先接一个，外置稳压 5 V 电源、接线端子、开关；先卸掉舵盘与负载。**产出：** 能解释并限制脉宽。

## PWM 是什么

定时器按时钟计数，在指定计数值翻转输出，产生周期脉冲。设定时器时钟为 `f_timer`，预分频器 PSC，周期寄存器 ARR：

```text
计数频率 = f_timer / (PSC+1)
PWM 频率 = f_timer / ((PSC+1) × (ARR+1))
高电平时长 = CCR / 计数频率
```

对 84 MHz 定时器，PSC=83 后每个计数是 1 μs，ARR=19999 得到 20 ms 周期，即 50 Hz；CCR=1500 得到 1.5 ms 高电平。必须检查 Cube 时钟树中 **APB1 timer clock**，不要把 APB1 总线频率直接当定时器频率。

## 位置舵机与连续旋转舵机

本课程购买**位置型微舵机**。它根据脉宽请求某个位置；连续旋转型通常控制转速和方向，不能拿同一程序定位。50 Hz、1500 μs 是常见起点，范围和中位须查实际舵机规格。默认软件范围仅 1200～1800 μs，仍须脱载验证；不要盲扫 500～2500 μs。

脉宽不等于精确角度。齿隙、供电、安装方向和负载都会影响结果。先用纸刻度记下 1400、1500、1600 μs 的大致位置，不能把别人的“每度多少微秒”作为你的标定。

## 接线与启用顺序

遵循 [采购与接线](hardware.md)。信号接 PA0/TIM2_CH1，舵机电源接外置 5 V，GND 共地；第二轴用 PA1/TIM2_CH2。先确认厂家支持 3.3 V 控制信号。电源正端不能接入 MCU GPIO。

应用启动时 PWM 关闭，只有收到合法新命令才输出。通信超时和 STOP 会取消脉冲，某些舵机随后卸力，所以云台要有稳定支架、低重心与机械限位。电源开关用于独立断电，不把串口 STOP 当物理急停。

## 实操 L05

1. 在 CubeMX 配置 TIM2 两个 PWM 通道，核实实际时钟并计算 PSC/ARR。
2. 先不接舵机，用逻辑分析仪或示波器测周期和高电平（仪器可借用，不在首批必买）。普通万用表不能验证微秒波形。
3. 脱载接一个舵机，发送 1500，再 1450、1550；观察电源稳定性。
4. 装舵盘，逐步收窄允许范围；再加第二轴与轻载摄像头。

**通过条件：** 两轴方向标定记录齐全；能说明机械允许范围和软件范围；不出现持续顶死、明显发热或 MCU 重启；超时后 PWM 确实取消。
