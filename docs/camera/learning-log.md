# 实验记录模板

- 实验 ID / 日期：
- 本次只解决的问题：
- 已读讲义、前置验收：
- 程序提交 / 启动命令 / 工具版本：
- 硬件完整型号 / 供电 / 引脚 / 负载：
- 接线图或照片位置：
- 预期结果（单位、阈值、失败行为）：
- 本次只改变的一个变量：
- 实测值 / 波形 / 日志 / 画面：
- 成功、失败或未测：
- 原因假设与支持/反对证据：
- 下一步最小验证：
- 能否由别人按同样步骤复现：

例：L06 不拔电机电源，仅拔 USB 数据线；预期 MCU 在最后合法帧约 300 ms 后取消 PWM；示波器实测时间差填入此处。若 USB 也给整个系统供电，这次试验不能用于证明看门逻辑。
