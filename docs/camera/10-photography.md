# 10｜根据画面调整曝光与清晰度

**前置：** 07～09。**硬件：** 先用已有摄像头做能力测试；可控曝光不是所有廉价 USB 相机都有的能力。**产出：** 相机能力表和一组同场景参数对照图。

## 三个量先分清

曝光时间是每帧积累光的时间，变长通常更亮，也更容易运动模糊。增益放大信号与噪声，不等于增加收到的光。光圈控制镜头通光口径，便宜 USB 相机以及 Camera Module 3 通常没有可程序调整的光圈；不能在界面里画一个光圈滑块就认为硬件支持。

对焦改变清晰平面，不同于改变亮度。自动白平衡改变颜色还原，不同于识别物体本来的颜色。自动曝光与手动控制同时运行时可能互相覆盖，所以调参前先确认自动模式状态。

## 不要把所有画面平均成一个数

全画面平均亮度可能被明亮背景主导。为主体框定义 ROI（感兴趣区域），计算灰度中位数、高亮像素比例、拉普拉斯方差等。中位数能降低少量极亮像素影响；拉普拉斯方差是一个受纹理、噪声和运动影响的清晰度代理，不是通用“照片质量分数”。

策略先从规则开始：主体 ROI 太暗时，在运动模糊允许范围内增加曝光；曝光已达上限才增加增益；高亮溢出则减少曝光。用滞回和低更新频率避免来回跳变。先固定白平衡与场景，再评价曝光，避免一次调整四个参数而无法判断原因。

## USB 相机能力实操 L10A

```powershell
.\.venv\Scripts\python.exe examples/camera_tracker/camera_probe.py --camera 0
```

这个命令只打印后端、分辨率、帧率和属性读数；读数为 0 不能单独证明“不支持”，有些后端对不支持也返回 0。填一张表：参数、自动模式、驱动单位、可设范围、请求值、读回值、画面变化。

可选执行 `--set-exposure 数值`，只使用驱动说明或控制面板确认过的值。不同后端可能用对数刻度、100 μs 或别的单位；这里不会提供一个冒充跨平台通用的关闭自动曝光数值。先用系统相机控制面板关闭自动曝光，再做三档对照。如果不支持，保留失败结论，用离线图像练策略，后期升级 CSI 相机。

## 离线画面评估 L10B

```powershell
.\.venv\Scripts\python.exe examples/camera_tracker/quality.py --self-test
.\.venv\Scripts\python.exe examples/camera_tracker/quality.py --image your-photo.jpg
```

对同一主体拍暗、正常、过曝三张；记录 ROI 与指标。基础程序输出“评估”，不会自动改变相机硬件。把评估结果闭环执行到相机，需要下一阶段完成单位、范围、自动模式和元数据验证。

**通过条件：** 能区分“建议增加曝光”“驱动接受请求”“传感器实际使用该曝光”三种证据；不把后处理增亮称为相机曝光控制。树莓派的控制示例见 [第 13 课](13-edge.md)。
