# 08｜从颜色分割到主体位置

**前置：** 07。**硬件：** 摄像头、一张绿色纸或绿色小球；先不装云台。**产出：** 目标框、中心坐标和失败样本。

## 先建立能解释的基线

最初不训练神经网络。把画面转成 HSV，选出某一色相、饱和度和亮度范围内的像素，得到黑白掩膜。OpenCV 对常用 8 位 HSV 图的 H 范围是 0～179，S/V 是 0～255。绿色初始阈值可以从 H=35～85、S≥80、V≥50 开始，再用现场光照调节；它不是所有环境通用的答案。

```python
hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
mask = cv2.inRange(hsv, (35, 80, 50), (85, 255, 255))
```

找到掩膜中的连通轮廓，去掉面积太小的区域，取最大候选。开运算能清除孤立小点，但也可能删除小目标。任何预处理都要用失败样本验证，不能只看一张漂亮截图。

## 中心点怎么计算

对一片区域，`m00` 表示面积权重，`m10/m00`、`m01/m00` 是质心 x/y。`m00=0` 时不能相除。示例使用最大轮廓的外接框中心作为简单位置代理；它对不规则轮廓可能偏离质心，扩展实验可比较两种方法。

位置归一化为 `cx/W, cy/H`。边框宽高也归一化，后续可以评估主体大小。初版“最大绿色区域”不是语义识别；画面里另一件更大的绿色物体会抢走目标。

## 如何判断一次检测可用

面积太小、框中心跳变太大、目标过于靠边、图像太暗，都应记录为不稳定情况。基础程序只做最小面积过滤和短时目标缺失停机，尚无完整多目标身份维护；这在 [识别课](11-recognition.md) 作为进阶实现。

## 实操 L08

1. 绿色目标放在干净背景，记录 30 帧框中心。
2. 加另一张绿色纸，观察最大面积策略会怎样选目标。
3. 改变室内灯光、背景和目标距离，各录一小段视频。
4. 建立至少 20 张成功与 20 张失败截图的自有数据集，写出阈值对漏检和误检的影响。

**通过条件：** 能解释掩膜、候选和最终目标；知道算法何时会失败；目标消失时返回 None，而不是坐标 (0,0)。
