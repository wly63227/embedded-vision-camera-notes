# 毕业项目：可解释的自动构图云台相机

## 需求与边界

指定桌面场景、稳定室内光照、单个绿色目标或正脸；电脑处理画面，两轴微舵机承载轻型 USB 模块。V1 提供居中/三分点构图、目标丢失与通信故障停机、日志。V2 添加分场景识别评估和画面质量建议；支持手动控制的设备再验证曝光执行。独立相机设备放 V3。

首版没有无刷增稳、外部角度反馈、通用物体理解、自动审美评分、真实相机载荷能力，也没有跨所有 USB 后端统一的曝光单位。

## 里程碑

| 阶段 | 可以演示的最小结果 | 必备材料 |
|---|---|---|
| M0 | 模拟误差下降，目标消失后 STOP | CSV、启动命令 |
| M1 | 单轴、双轴受限运动 | 接线图、PWM/供电记录 |
| M2 | 画面绿色框和归一化位置 | 成功与失败样本 |
| M3 | 居中与三分点构图 | 误差曲线或 CSV、对照视频 |
| M4 | 故障均有确定回退 | 故障表、固件版本 |
| M5 | 模式识别评估与拍摄策略 | 数据划分、P/R、能力表、ROI 对照 |

“约 300 ms”是代码阈值加主循环、串口与测量的误差，不是已认证的实时上界。硬件实验必须量出实际行为。
