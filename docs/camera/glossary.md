# 当前项目的术语

| 词 | 用自己的话解释 |
|---|---|
| MCU | 带内存和外设的小型控制芯片 |
| GPIO | 用来读写数字电平的引脚 |
| HAL | 厂商提供的硬件抽象接口库 |
| PWM | 按固定周期输出可变高电平时长的波形 |
| μs / ms | 微秒 / 毫秒；1000 μs = 1 ms |
| UART | 需要约定波特率等格式的字节通信外设 |
| VCP | USB 虚拟串口，让电脑通过 COM 口访问串口数据 |
| XOR | 按位异或，此处用于简单校验 |
| 超时/看门 | 新数据没按期到达，主动进入确定的降级状态 |
| 锁存 | 进入 STOP 后保持停止，需要明确重新启动 |
| UVC | USB 视频设备类；不代表所有相机参数都可调 |
| BGR/HSV | 颜色的不同数值表示方法 |
| ROI | 选定的局部图像区域，例如主体人脸框 |
| 归一化 | 把像素位置除以画面尺寸，变为 0～1 的相对位置 |
| 负反馈 | 动作使当前误差减小，而非不断扩大 |
| 死区 | 很小的误差暂不纠正，减少抖动 |
| 饱和/限幅 | 指令达到允许上限或下限 |
| 精确率/召回率 | 预测为目标的有多少正确 / 真正目标有多少被找到 |
| IoU | 两个框交集面积除以并集面积，用于比较位置重合 |
| 推理 | 使用模型处理新输入，不等于在设备上重新训练 |
| AE / AWB / AF | 自动曝光 / 自动白平衡 / 自动对焦 |
| CSI | 相机传感器与计算板间的一种高速接口，非普通 GPIO |
