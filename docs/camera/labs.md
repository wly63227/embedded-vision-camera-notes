## 首个周末的具体安排

第一小时跑 L00；第二小时阅读电学并画接线图；第三小时核对采购型号和价格；硬件未到时学习 C 与 Python；到货后先验证开发板 USB 和万用表，再接任何舵机。不要首日同时装相机、接电机、启动识别和修改固件。

## 故障注入时怎样避免混淆

每次只改变一个变量。例如保持舵机电源与机械状态不变，只拔 USB 数据线；否则“舵机不动”可能只是所有供电同时断了，不能证明通信看门狗生效。测断线停机时应观测 PWM 输出是否取消，并记录最后合法帧时间。
