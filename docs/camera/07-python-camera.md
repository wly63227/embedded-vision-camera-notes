## Python 只学当前会用到的部分

Python 用缩进表示代码块。变量不必提前写类型，但单位与取值范围仍需自己管理。列表存放多项数据，字典通过名字查值，函数返回计算结果。模块是可导入的 `.py` 文件。`if __name__ == '__main__':` 使脚本直接运行时才进入入口。

在仓库根目录建独立环境，避免不同项目依赖相互干扰：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-camera.txt
.\.venv\Scripts\python.exe examples/camera_tracker/live.py --camera 0
```

直接调用虚拟环境的 Python，不需要修改系统脚本执行策略。退出按 q，紧急停止运动按空格；默认没有串口参数，所以只显示与计算，不会驱动硬件。第一次接电机前必须先完成脱载调试。

## 一张图像是什么

常见彩色图像是 `H×W×3` 的数字数组。行是 y，列是 x，原点在左上角。OpenCV 通常按 BGR 通道顺序存储，和许多图像工具的 RGB 顺序不同。`frame.shape` 返回尺寸，不能将宽高顺序颠倒。

```python
ok, frame = cap.read()
if not ok:
    # 结束处理，不拿上一帧冒充新帧
    raise RuntimeError('相机没有返回有效帧')
h, w = frame.shape[:2]
```

尺寸设置和曝光设置都是向后端提出请求，并非保证生效。设备、操作系统驱动和 OpenCV 后端共同决定实际能力；设置返回成功也要读回并观察画面。详见 [相机能力实验](10-photography.md)。
