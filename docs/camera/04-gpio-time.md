# 04｜GPIO、按键与不阻塞的时间

**前置：** 03。**硬件：** 开发板板载 LED 与按钮。**产出：** 按键切换闪烁速度，同时仍能响应事件。

## 输入和输出

输出脚由程序驱动高低电平，输入脚读取电平。悬空输入容易受干扰，需要上拉或下拉提供默认状态。板载 LED 和按键的电路由板子原理图决定：不能把别的板子的引脚和有效电平照搬过来。

在 NUCLEO-F401RE 板级配置里查找 LD2（通常 PA5）和 B1（PC13），先查看生成的 GPIO 宏及读数，确认按下与松开对应哪种电平。初始化后用 `HAL_GPIO_TogglePin(LD2_GPIO_Port, LD2_Pin)` 切换 LED。

## 让两个任务同时推进

最初可以 `HAL_Delay(500)` 观察闪灯，但主循环被卡在延时中，不能及时解析控制命令。改成时间戳判断：

```c
uint32_t now = HAL_GetTick();
if ((uint32_t)(now - last_toggle_ms) >= period_ms) {
    last_toggle_ms = now;
    HAL_GPIO_TogglePin(LD2_GPIO_Port, LD2_Pin);
}
```

它不会创建第二个线程，只是每次循环都很快检查“到时间了吗”。`last_toggle_ms` 要在循环外保存。无符号减法按模运算处理计数回绕，约束是每次检查间隔远小于一个完整计数周期。

## 消抖与中断

机械按钮按下时会产生多次快速跳变。用软件要求新电平持续稳定约 20 ms 才承认一次状态变化；这个时间需按按钮实测。可以先轮询，再学 EXTI 中断。中断里只记录事件，不能长时间打印或等待。

## 实操 L04

1. 先做 500 ms 阻塞闪灯，按键时打印或观察响应。
2. 改成时间戳闪灯，主循环不断读取按钮。
3. 记录原始电平和消抖后的事件数，连按十次。
4. 每次“按下事件”切换 200/800 ms 闪烁周期。

**通过条件：** 十次按下只得到十次有效事件；闪灯期间按钮仍可响应；主循环没有长延时。外部电路尚未接入时可放心使用断点，后续调电机时必须先处理输出状态。
