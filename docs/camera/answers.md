# 自编练习参考解

这些是讲解用参考，不是教师标准答案。工程题允许不同方案，但必须说明条件、单位、失败行为与验证方法。

**E00：** `600/800 - 1/3 = 5/12 ≈ 0.4167`。正值仅表示画面位置比目标偏右；安装朝向决定增大脉宽会把画面移向哪边，所以 sign 要实测。

**E01：** 约从 1.3 mA 降到 0.65 mA，假设 LED 压降近似不变。两个电源实际电压有差异，直接并联可能互相灌电流；需要专门的电源并联/隔离设计。

**E02：** 在 8 位 unsigned char 的前提下回绕为 0，C 对无符号数按模运算。`now-last` 能跨一次计数回绕计算差值，前提是检查间隔没有跨越完整计数周期、超时范围合理；任意长时间后不能从同样计数值推断经过几圈。

**E03：** CPU 暂停不保证外设自动冻结，PWM 可能持续最后值；软件看门狗也不会继续由主循环执行。先脱载或关闭动力，再打断点；若要依靠调试冻结，需查芯片的专用调试冻结配置，不能假定所有外设支持。

**E04：** 中断一直不退出，可能阻塞同级/低优先级中断，也阻止主循环检测超时和解析命令。改为记录边沿、时间戳，在主循环做状态与消抖。

**E05：** PSC=47，使 48 MHz/48=1 MHz；ARR=19999，每 20000 计数一周期；CCR=1500。核实真实定时器时钟而非仅凭系统主频。

**E06：** 噪声、重放包或不完整帧可能持续产生字节，却没有新的有效决策。只在完整校验、范围、序号均通过的 P 帧刷新。当前样例坏校验还会锁存停机。

**E07：** 连续画面坐标近似为 (320,240)、(640,480)，归一化为 (0.5,0.5)。像素索引最大值比尺寸少 1，精确像素中心约定可有半像素差异，必须在标定时统一。

**E08：** 色相与亮度分离后更容易设颜色范围，但光源颜色、自动白平衡、欠曝、反光与低饱和度仍会改变数值。保留不同条件的失败样本，不能把阈值当不变的物理颜色定义。

**E09：** 图像延迟、舵机惯性、齿隙与噪声会让过大的反馈来回纠偏。先用小增益、死区和限速，排除方向错误；积分可能在脉宽饱和时累积，需要防积分饱和，首版不急于增加复杂度。

**E10：** 明亮背景能掩盖主体欠曝，应同时检查主体和整体高亮溢出。延长曝光收集更多光但可能模糊；增益不会增加收到的光，并放大噪声。

**E11：** 准确率 80%，召回率 0；没有正预测，精确率分母为 0，应报告未定义并说明策略。跟拍需要对目标真正检出，单看准确率会被多数负样本误导。

**E12：** MCU 按最后一个合法帧独立计时，主机冻结后仍应超时取消输出。取消 PWM 可能卸力、负载下垂，需要稳定支架与机械支持；它不是刹车保证。

**E13：** 等待控制生效并读取新的元数据，设置最大等待帧数/时间；超过上限就降级并记录。API 调用成功只是请求被接受，不是这张照片的实际传感器参数证明。

扩展题的评价标准：有可重现数据、清楚区分测量与推断、明确失败回退；不要求首版就实现所有扩展功能。
