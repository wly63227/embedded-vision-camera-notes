## 必须核对的接线

| 信号/供电 | 连接 | 说明 |
|---|---|---|
| 电脑 USB | Nucleo 板载 ST-LINK 口 | 给板供电、烧录和虚拟串口；不要从舵机电源给板回灌 |
| 水平信号 | PA0 / TIM2_CH1（核对板上 A0） | 3.3 V 逻辑，先确认舵机输入兼容 |
| 俯仰信号 | PA1 / TIM2_CH2（核对板上 A1） | 同上 |
| 舵机红线/V+ | 外置 5 V 经开关后的正端 | 不连接 MCU 3V3 或 GPIO；颜色以实际说明为准 |
| 舵机 GND | 外置电源负端分线端子 | 两个动力回路都直接回这里 |
| MCU GND | 同一个电源负端分线端子 | 建立共同信号参考；不要让舵机回流经过 MCU |
| 摄像头 USB | 电脑 USB | 别扭紧线缆；检查转动时不会牵拉或缠绕 |

```text
外置5V + ──低压开关──┬──水平舵机 V+
                     └──俯仰舵机 V+
外置5V - ──分线端子──┬──水平舵机 GND
                     ├──俯仰舵机 GND
                     └──Nucleo GND
Nucleo PA0 ───────────水平舵机信号
Nucleo PA1 ───────────俯仰舵机信号
电脑 USB ────────────Nucleo；另一口连接摄像头
```

断电接线，脱载测试中位，再逐步装支架。5 V/3 A 是预算起点，若规格或峰值测试要求更高则换匹配电源；不要把开关电源的电流标称当成限制舵机堵转电流的机制。
