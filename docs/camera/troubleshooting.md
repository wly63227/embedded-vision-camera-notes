# 排错：先缩小故障范围

| 现象 | 先做的验证 | 常见原因与处理方向 |
|---|---|---|
| 板有电但找不到调试器 | 换已知可传数据的线，只接开发板 | 充电线、驱动、USB 口；确认 ST-LINK 接口 |
| 串口存在但无动作 | 无舵机测 PWM、核对 115200/8N1/LF | 串口选错、ARM 未发、CRLF 被拒、校验错、STOP 锁存 |
| 舵机抖动、板重启 | 脱载，只动单轴，测外置电源与接地 | 电源峰值不足、接触电阻、回流经过 MCU、机械顶死 |
| 相机越转越偏 | 立即 STOP，小步单轴标定 sign | 反馈方向错误，不要先增大 Kp |
| 一直来回抖 | 固定目标、减速、加死区，量帧延迟 | 增益过大、齿隙、误检、缓存旧帧、供电噪声 |
| 绿色纸有时消失 | 显示掩膜，锁定白平衡/光照做对照 | HSV 范围、低饱和/欠曝、反光、目标太小 |
| 多人时相机乱跳 | 先单人测试，再看候选框 | 最大框策略没有身份连续性，加入人工锁定/IoU |
| 曝光 set 返回 true 但没变化 | 查自动模式、驱动单位，拍三档对照 | 后端不支持、AE 覆盖、范围不对、参数延迟生效 |
| 按 STOP 后云台下垂 | 支撑负载，检查舵机行为 | 停 PWM 可能卸力；需机械支持，不是继续发送旧指令 |
| 断点时看门不生效 | 先断动力，观察 CPU 暂停状态 | 软件看门靠 CPU 执行，断点暂停不能保证实时停机 |
| Python 提示 No module named cv2 | 用安装依赖的同一个 Python 执行 | 检查 `.venv/Scripts/python.exe` 与 `-m pip` 配对 |
| 模拟通过但实物不稳定 | 回退单轴脱载，检查波形/供电/方向 | 模拟模型无真实惯性、摩擦、线缆牵拉与延迟 |

每轮只改一个参数；问题报告提供最短复现命令与“预期/实际”。不要通过删除限位、取消超时、无限重发 ARM 或把所有异常忽略来让演示继续。
