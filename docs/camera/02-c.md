# 02｜C 语言：把数值变成受约束的动作

**前置：** 00。**硬件：** 电脑。**产出：** 会读舵机限幅函数、能用断点解释变量变化。

## 变量、类型与判断

变量是带名字的存储位置。`int pulse = 1500;` 声明一个整数，单位由程序设计者规定，这里是微秒。`=` 是赋值，`==` 是比较。`if` 决定条件成立时执行什么，`for` 重复有限次数，函数把一个任务包装成有输入和输出的模块。

```c
int clamp_pulse(int pulse) {
    if (pulse < 1200) return 1200;
    if (pulse > 1800) return 1800;
    return pulse;
}
```

输入 1900 返回 1800，这表示软件允许的命令上限，不表示舵机真的到达某个角度。物理单位应写进变量名，例如 `pulse_us`、`elapsed_ms`。整数除法 `1/3` 等于 0；需要小数时用 `1.0/3.0`。`uint16_t`、`uint32_t` 表示固定宽度无符号整数，定义在 `stdint.h`。

## 数组、指针和边界

数组是连续的多个元素。`char line[64]` 只有 0～63 这 64 个合法下标。字符串末尾还需要 `\0`；一条最长 63 字节的字符串才放得下。指针存放地址，`&x` 取地址，`*p` 访问该地址的对象。传给函数的数组通常不会自动携带长度，必须额外传长度。

越界不是“偶尔读错一个数”那么简单，可能破坏控制状态。因此串口程序会在缓冲区满时丢弃整行，等换行再恢复。`volatile` 表示变量可能被异步改变，不能让读写自动变得原子，也不能代替正确的并发设计。

## 位运算够用就学

二进制位只有 0 和 1。`1u << 5` 将第 5 位设为 1，`value & mask` 检查某些位。GPIO 驱动底层会操作寄存器；入门先用 HAL，看懂寄存器映射后再深入。不要先背整本寄存器手册。
