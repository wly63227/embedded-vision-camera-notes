# 传感器与信号链

物理 AI 的模型上限经常由数据质量决定，而不是网络结构。

## 传感链路

```text
物理量 → 敏感元件 → 模拟前端 → ADC/数字接口 → 标定 → 滤波 → 时间同步 → 特征/状态
```

## 关键指标

- 量程、分辨率、精度、重复性、零偏和漂移。
- 采样率、带宽、延迟和抗混叠。
- 噪声密度、温漂、饱和与安装误差。
- 数据时间戳究竟代表“采样时刻”还是“收到时刻”。

## 常见传感器

| 类型 | 用途 | 重点问题 |
|---|---|---|
| 编码器 | 位置/速度 | 计数回绕、方向、速度差分噪声 |
| IMU | 角速度/加速度 | 零偏、坐标系、温漂、振动 |
| 相机 | 视觉感知 | 曝光、标定、时间同步、带宽 |
| ToF/超声 | 距离 | 盲区、视场、材料和多径 |
| 力/触觉 | 接触反馈 | 放大、漂移、过载、机械耦合 |
| 电流/电压 | 驱动与保护 | 隔离、采样同步、量程和热漂 |

## 数据接口约定

每条样本至少包含：

```text
timestamp | sequence | frame_id | value | unit | validity | error_flags
```

不要只传一个裸 `float`。坐标系、单位、时刻和有效性缺一不可。

## 标定步骤

1. 定义坐标系和正方向。
2. 采集覆盖工作范围的原始数据。
3. 估计零偏、比例、非正交或温度项。
4. 用独立数据验证，不在同一数据上自证。
5. 参数带版本和 CRC 保存；记录适用硬件序列号。

## 实验阶梯

1. 读取 IMU `WHO_AM_I`，失败时不死锁。
2. 以稳定频率采集，统计均值、方差、峰峰值和丢样率。
3. 静止六面标定加速度计；画出标定前后误差。
4. 编码器测位置和速度，对比固定窗口与低通滤波的延迟。
5. 为相机/IMU/编码器统一时钟或建立时间偏移估计。
