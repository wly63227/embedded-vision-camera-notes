# C 语言与 MCU 实时基础

返回：[[00-物理AI嵌入式学习地图]]

## C 语言核心

- 定宽整数、符号与溢出、位操作。
- 指针、数组、结构体、生命周期和内存对齐。
- `const`、`volatile`、`static`；理解 `volatile` 不提供原子性。
- 头文件、模块边界、错误码和防御式接口。
- Flash、`.data`、`.bss`、栈与堆。

## MCU 核心

- 复位、启动代码、向量表和中断。
- GPIO、EXTI、定时器、PWM、ADC、DMA。
- UART、I²C、SPI；调试器、寄存器与 map 文件。
- 数据手册、参考手册、原理图和勘误表的区别。

## 实时思维

实时不是“平均很快”，而是关键动作在截止期限内完成。每个周期任务记录：

- 周期和截止期限。
- 最坏执行时间（WCET 的实测上界）。
- 抖动容许范围。
- 超时后果和降级动作。

典型协作式主循环：

```c
for (;;) {
    uint32_t now = platform_millis();
    sensor_update(now);
    control_update(now);
    actuator_update(now);
    protocol_update(now);
    safety_update(now);
}
```

除最初点灯外，不用长时间阻塞延时组织系统。

## 必做实验

1. LED + 按键消抖，连续 30 次无误触发。
2. 定时器输出 1 kHz PWM，用仪器验证频率与占空比。
3. ADC 由定时器触发，DMA 搬运一批样本。
4. UART 环形缓冲区处理半包、粘包和溢出。
5. 制造数组越界或栈不足，学习读取 HardFault 现场。

## 验收

- 能从目标频率反推定时器参数。
- 能解释 ISR 中哪些操作危险。
- 能证明一个周期任务不会因 tick 回绕失效。
- 编译警告均已解释，等待硬件状态的循环都有超时。
