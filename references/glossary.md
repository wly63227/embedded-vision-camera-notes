# 嵌入式术语表

| 术语 | 含义 |
|---|---|
| MCU | 集成 CPU、存储器和外设的微控制器 |
| SoC | 集成更复杂系统组件的片上系统 |
| BSP | 板级支持包，封装具体板卡差异 |
| HAL | 硬件抽象层 |
| ISR | 中断服务程序 |
| NVIC | Cortex-M 的嵌套向量中断控制器 |
| DMA | 外设与内存间直接搬运数据的控制器 |
| GPIO | 通用数字输入输出 |
| ADC / DAC | 模数 / 数模转换器 |
| UART | 异步串行通信外设 |
| I²C | 两线、带地址、开漏式同步总线 |
| SPI | 全双工、主从式同步串行接口 |
| PWM | 通过占空比表达控制量的脉宽调制 |
| Watchdog | 未按期喂狗时复位系统的监控定时器 |
| Bootloader | 启动、校验和更新应用固件的程序 |
| RTOS | 提供实时调度与同步原语的操作系统内核 |
| Race condition | 结果依赖不可控执行顺序的竞态 |
| Priority inversion | 高优先级任务被持锁的低优先级任务间接阻塞 |
| Jitter | 周期或响应时间相对理想时刻的波动 |
| Endianness | 多字节数据在内存/协议中的字节顺序 |
| Debounce | 消除机械触点抖动造成的重复边沿 |
| HardFault | Cortex-M 中用于汇总严重故障的异常 |
